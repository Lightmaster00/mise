# Mise — brand guide

**Name**: Mise (from *mise en scène*). **Tagline**: *Your designs, on stage.*

## Icon

A macOS tile (continuous corners) as a cream photo studio: a phone in a warm silver frame floats,
slightly tilted, above its own soft shadow. Its screen goes from deep indigo to violet to a warm peach.
Generated by `make-icon.py` → `icon.svg` → `icon-*.png` and `AppIcon.icns`.

## Colors

| Name    | Hex       | Use |
|---------|-----------|-----|
| Cream   | `#FBF8F3` | icon background, light surfaces |
| Sand    | `#E6DDCF` | studio floor |
| Indigo  | `#2E2A5E` | screen gradient start, dark text |
| Violet  | `#6B5BB4` | accents |
| Peach   | `#E9A27F` | screen gradient end, warm accents |

The interface uses the system accent color, like every Mac app.
