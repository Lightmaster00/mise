# Mise — brand guide

**Name**: Mise (from *mise en scène*). **Tagline**: *Your designs, on stage.*

## Icon

A macOS tile (continuous corners) as a night-blue stage: a warm spotlight falls on a white pedestal
where a phone stands, its screen in a violet-to-pink gradient. Generated by `make-icon.py` →
`icon.svg` → `icon-*.png` and `AppIcon.icns`.

## Colors

| Name      | Hex       | Use |
|-----------|-----------|-----|
| Stage     | `#2B2F6B` | icon background, website |
| Night     | `#14142E` | dark backgrounds |
| Spotlight | `#FFE7B8` | light beam, highlights |
| Violet    | `#7B6BFF` | screen gradient start, accents |
| Pink      | `#FF7AA8` | screen gradient end |

The interface uses the system accent color, like every Mac app.
